# 🦄 مدرسة البنات للإنجليزية

موقع تعليمي للبنات لتعلم الحروف الإنجليزية — منفصل تمامًا عن بوابة الخدمات المساندة،
لكنه يستخدم **نفس مشروع Firebase** (`supportive-med`) للمصادقة وقاعدة البيانات،
مع مجموعات بيانات مستقلة تبدأ بـ `edu` حتى لا تختلط بأي بيانات أخرى.

## ماذا يقدم الموقع؟

| الصفحة | الوصف |
|---|---|
| `/` | تسجيل الدخول (يوزر خاص لكل بنت) + اختيار النشاط |
| `/learn` | كل الحروف كبيرة وصغيرة `A a` مع النطق الصوتي وكلمة مثال بالإيموجي |
| `/flashcards` | استعراض عشوائي للحروف (أحيانًا كبير وأحيانًا صغير) بلا تكرار حتى تكتمل الـ26 |
| `/quiz` | اختبار من 10 أسئلة عشوائية: «استمعي واختاري» أو «طابقي الكبير مع الصغير» — والنتيجة تُحفظ |
| `/admin` | لوحة المدير: إنشاء حسابات البنات، وقت المذاكرة الكلي واليومي، الحروف المستعرضة، ونتائج الاختبارات بالتفصيل (حتى الحروف التي أخطأت فيها كل بنت) |

- **النطق الصوتي**: عبر Web Speech API من المتصفح مباشرة — لا يحتاج ملفات صوتية ولا سيرفر (يعمل في كروم وسفاري وإيدج).
- **تتبع وقت المذاكرة**: يُحتسب فقط عندما تكون الصفحة ظاهرة وهناك تفاعل (يتوقف العد بعد دقيقتين بلا لمس)، ويُحدَّث كل 20 ثانية في `eduSessions`.
- **الدخول**: نفس أسلوب البوابة (اسم مستخدم يتحول داخليًا لبريد). حسابات البنات على نطاق مستقل `@edu.app`، وحساب المدير في البوابة يدخل هنا بنفس اليوزر والباسورد (يجري تجريب النطاقين تلقائيًا).

## البيانات في Firestore (منفصلة عن البوابة)

- `eduUsers/{uid}` — حسابات الموقع التعليمي (الاسم، اليوزر، الدور، الرمز، معطّل/نشط)
- `eduSessions/{id}` — جلسات المذاكرة: `uid, activity, date, seconds, letters, startTs, lastTs`
- `eduQuizzes/{id}` — نتائج الاختبارات: `uid, type, correct, total, pct, durationSec, details[]`

## خطوات التشغيل (مرة واحدة)

### 1) قواعد Firestore
قواعد المشروع تُدار من مستودع `supportive`. افتح `firestore.rules` هناك،
والصق محتوى الملف [`firestore-learning.rules`](firestore-learning.rules)
**قبل** قاعدة الرفض الأخيرة `match /{document=**}`، ثم من مستودع supportive:

```bash
firebase deploy --only firestore:rules
```

### 2) موقع استضافة ثانٍ في نفس المشروع
حتى لا يمس هذا الموقع استضافة البوابة، أنشئ Hosting site ثانيًا:

```bash
firebase hosting:sites:create girls-learning-en --project supportive-med
```

> إن كان الاسم محجوزًا اختر اسمًا آخر وعدّل حقل `"site"` في `firebase.json`.

### 3) النشر (من هذا المستودع)
```bash
firebase deploy --only hosting --project supportive-med
```

الموقع سيصبح على: `https://girls-learning-en.web.app`

### 4) السماح للنطاق الجديد في المصادقة
من Firebase Console → **Authentication → Settings → Authorized domains**
أضف: `girls-learning-en.web.app`

### 5) أول دخول
- ادخل بحساب المدير (نفس يوزر وباسورد بوابة الخدمات المساندة) — سيُنشأ ملفه تلقائيًا.
- من «📊 لوحة المتابعة» أضف حسابًا لكل بنت (اسم، يوزر، باسورد، رمز 🦄).
- كل بنت تدخل بيوزرها من أي جهاز، وأنت تتابع كل شيء من اللوحة.

## التطوير محليًا

```bash
firebase serve --only hosting
# أو أي خادم ملفات ثابت على مجلد public (مع مراعاة أن cleanUrls تعمل في الاستضافة فقط)
```
