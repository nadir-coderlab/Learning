# 🧠 ملف المتدرب — ذاكرة المتابعة

> هذا الملف مرجع دائم (لي ولك) عن مستواك وسلوكك وأخطائك، عشان كل تحديث للخطة يركّز على نقاط ضعفك بدل ما يبدأ من الصفر.
> البيانات الحيّة (كل درجة وكل غلطة) محفوظة في متصفحك داخل المدرّب. هنا الخلاصة والقرارات.

## 1) الوضع الحالي

| البند | القيمة |
|---|---|
| آخر نتيجة رسمية | تجريبي Duolingo (31 أغسطس 2026): **60–80 · Intermediate · IELTS 4–5** |
| التقدير الواقعي | 70–75 (B1) — التجريبي عادة أقل شوي من الحقيقي |
| الهدف القريب | **90+** بالاختبار الحقيقي (ليلة + يوم مذاكرة) |
| الهدف البعيد | **120** بالمحاولة الثانية بعد أسبوعين تدريب |
| أهم رافعات الدرجة | ① لا فراغ أبدًا ② كتابة 120+ كلمة / 40+ بالصور ③ محادثة تملأ الوقت كله (OREO) ④ إملاء بحرف كبير ونقطة وتخمين لكل كلمة ⑤ السرعة والشكل |

## 2) طريقتك بالمذاكرة (تفضيلات ثابتة — لا تتغير)

- **ما تفتح أي مصدر ثاني**: كل شي لازم يكون داخل الخطة والمدرّب ومركز المذاكرة.
- **الشرح بالعامية السعودية «على بلاطة»**: فكرة بسطر ← أمثلة (الإنجليزي بسطر والعامي تحته) ← تريكات غلط/صح.
- **الإجابة كلمة أو كلمتين بس** في تمارين القواعد (مثل `a` أو `an`)، مو الجملة كلها.
- **الإنجليزي والعربي ما يختلطون بسطر واحد** بشكل ملخبط: الإنجليزي LTR بسطره، والعربي RTL بسطره.
- **الكلمات اللي تغلط فيها تتكرر عليك** تلقائيًا، وأي كلمة تحس إنك ما حفظتها تعلّم عليها بزر «🔁 راجعها».

## 3) كيف يخزّن المدرّب سلوكك وأخطاءك

كل شي في مفتاح واحد بمتصفحك `detTrainer.v1`:

| الحقل | وش فيه |
|---|---|
| `best` / `done` | أفضل درجة وعدد الجلسات لكل تمرين |
| `hist` | آخر 40 درجة لكل تمرين بالوقت — منها يُحسب متوسط آخر 3 جلسات لكل مهارة |
| `miss` | كل غلطة: الكلمة، معناها، ملاحظة (الدرس/الفخ)، النوع (`rs` كلمات، `fib` فراغات، `rc` فقرة، `lt` إملاء، `vocab` مفردات، `lesson` قواعد)، عدد مرات الغلط `n`، الصندوق `box` 0→2، وموعد الرجوع `due` |
| `mastered` | اللي عرفته 3 مرات متباعدة (انشال من المراجعة) |
| `vocab` / `lessons` / `plan` | حالة البطاقات (أعرفها/أراجعها)، الدروس المكتملة، مهام الخطة المنجزة |

**التكرار المتباعد:** غلط أو «راجعها» → صندوق 1 (يرجع فورًا) → عرفتها → صندوق 2 (بعد 4 ساعات) → عرفتها → صندوق 3 (بعد 20 ساعة) → عرفتها → أتقنتها. أي غلطة ترجّعها للصندوق الأول.

**التمارين تتكيّف:** Read and Select يحط لك حتى 4 كلمات حقيقية و3 وهمية غلطت فيها قبل، Fill in the Blanks حتى 3 جمل بكلماتك الغلط، Listen and Type جملتين رجعت لك، واختبار المفردات نص أسئلته من أخطائك.

**التحليل في تبويب «اليوم»:** متوسط آخر 3 جلسات لكل مهارة (أحمر تحت 60%، أصفر تحت 75%)، و3 تمارين «ركّز اليوم على» (الأضعف أو اللي ما جربته)، وعدّاد المراجعة المستحقة، وأكثر الكلمات اللي تغلط فيها.

## 4) كيف ترسل لي مستواك عشان أحدّث خطتك

1. افتح المدرّب ← تبويب «اليوم» ← بطاقة «🧠 ملفي وبياناتي».
2. اضغط **«🧾 ملخص مستواي»** ← «نسخ الملخص» ← الصقه لي في المحادثة.
   (أو **«📤 نسخة بياناتي»** لو تبغى ترسل كل التفاصيل، وهي نفسها تنفع للاسترجاع على جهاز ثاني بزر «📥 استرجاع».)
3. أنا أقرأ: أضعف مهارة، تاريخ الدرجات، الكلمات المتكررة بالغلط، والدروس اللي فيها أخطاء — وأعدّل الخطة والدروس عليها.
